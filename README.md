# 🎯 보드게임 세트 + 바투(Batoo) 재현

2009년 서비스 종료된 바둑 변형 게임 **바투**를 재현하고, 주변에 보드게임/카드게임 18종을 붙인 프로젝트.
모든 게임은 의존성 없는 **단일 HTML 파일** — 브라우저만 있으면 돌아간다.

## 게임 목록 (19종)

모든 게임 우하단 **📖 룰** 버튼 — 규칙·족보·조작법이 게임 안에 들어있다.

## 실행

```bash
# 그냥 놀기 (허브 + 전 게임 + 바투 AI + 온라인 API 전부)
python3 cloud_server.py            # → http://localhost:8890/

# 인터넷에 공개해서 친구랑 온라인 대전 (서버+터널 원클릭)
./start_online.sh                  # → 뜨는 https://xxxx.lhr.life 주소 공유

# 24시간 고정 주소 서버 (무료, 가입 필요)
# → DEPLOY.md 참고 (Render 블루프린트 — 클릭 몇 번이면 끝)
```

개별 서버로 띄우려면: `python3 server.py`(바투 전용, 8890) / `python3 games_server.py`(바둑·오목·체스·장기 온라인, 8891).

## 온라인 대전

바투 + 바둑·오목·체스·장기 5종 지원. 방 코드(4자리)로 매칭, 서버 권위(바투) 또는 수 중계(나머지) 방식.
상대에게 서버 주소만 보내면 됨 — 설치 불필요.

## 바투 AI

- 게임 내 "신경망" 난이도 = `batoo_net.pt` (알파제로 방식 자가대국 학습, iter739, vs UCT 62%)
- torch 없는 환경에선 자동으로 UCT(순수 MCTS)로 폴백 — 서버는 표준 라이브러리만으로 동작
- 학습을 직접 돌리려면 `README_LINUX_TRAIN.md` 참고

## 개발 문서
