⚾ 야구 전력분석

팀 목록

⭐ = 우리 팀 (자동 매치 기준)

게임원에서 자동으로 받아오기

내 컴퓨터 터미널에서 리그 주소로 한 번 실행하면 리그 전체 팀의 타자·투수 기록과 경기 결과를 받아옵니다.

python3 gameone_sync.py "https://www.gameone.kr/league/?lig_idx=리그번호" --serve

끝나면 이 화면이 자동으로 열리고 기록이 반영됩니다. 새 경기가 끝날 때마다 같은 명령을 다시 실행하면 최신 기록으로 갱신됩니다(타구 기록은 유지). 리그 주소는 게임원에서 리그 첫 화면 주소창에 있는 주소입니다.

게임원 기록 붙여넣기 (자동 수집이 안 될 때)

게임원 팀/리그 기록 페이지에서 표를 제목줄(이름·타수·안타…)까지 포함해 드래그 → 복사(Ctrl+C) → 아래에 붙여넣기. 열 이름을 자동 인식합니다. 표에 팀 열이 있으면(리그 전체 기록) 팀별로 자동 분류됩니다.

타자

투수

단타 장타(2·3루타·홈런) 아웃·실책
선수를 고르고 아래 결과를 선택한 뒤 그라운드를 클릭하면 타구가 기록됩니다.

타구 성향

중계 텍스트로 일괄 입력

게임원 문자중계/기록지 문장을 붙여넣으면 줄마다 선수 이름 + 방향(좌중간·유격수 등) + 결과(안타·땅볼 등)를 찾아 기록합니다. 이름이 없는 줄은 위에서 선택한 선수로 들어갑니다.

타구 목록

vs

우리 팀 기준 자동 매치

등록된 모든 상대와 자동으로 맞붙여 예상 승률·우위 영역을 계산합니다.

리그 전체 매트릭스 (행 팀의 예상 승률)

파랑 = 행 팀 우세, 주황 = 열 팀 우세, 회색 = 박빙. 칸을 누르면 상세 비교로 이동.

저장·백업

모든 기록은 이 브라우저에 자동 저장됩니다. 다른 기기로 옮기거나 백업하려면 파일로 내보내세요.

설정

사회인 리그가 7이닝제면 7로 두면 ERA·실점률이 경기 기준으로 맞춰집니다.

📖 사용법

1. 기록 가져오기

  • 게임원 → 팀(또는 리그) → 기록 메뉴의 타자/투수 표를 제목줄까지 드래그해 복사 → [팀·가져오기]에 붙여넣기.
  • 인식하는 열: 이름, 등번호, 팀, 경기, 타석, 타수, 득점, 안타, 2루타, 3루타, 홈런, 타점, 도루, 4구(볼넷), 사구, 삼진, 희타, 희비, 병살, 실책 / 투수: 승, 패, 세, 홀드, 이닝, 타자, 피안타, 피홈런, 4구, 사구, 탈삼진, 실점, 자책.
  • "홍길동(7)"처럼 이름 옆 괄호 숫자는 등번호로 처리합니다. 이닝 "5 2/3", "5.2"(=5⅔) 모두 인식.
  • 경기 결과는 "날짜 팀A 7 : 5 팀B" 형태 줄을 인식해 득실점·상대전적에 반영합니다.

2. 타구 방향

  • 그라운드 클릭으로 직접 기록하거나, 문자중계 문장을 붙여넣어 일괄 기록.
  • 방향 단어: 투수·포수·1루수·2루수·유격수·3루수·좌익수·좌중간·중견수·우중간·우익수·좌전·중전·우전·좌월·중월·우월·좌익선상·우익선상.
  • 선수의 타석(좌/우)을 선수 상세에서 지정하면 당겨치기/밀어치기 비율과 수비 시프트 추천이 정확해집니다.

3. 전력 비교·자동 매치 계산식

  • 공격지수 = (팀 출루율×장타율) ÷ 리그 평균, 경기 결과가 있으면 경기당 득점 비율과 반반 섞음.
  • 실점지수 = 팀 실점률(이닝당 실점×기준이닝) ÷ 리그 평균, 경기 결과 있으면 경기당 실점과 반반.
  • 예상 득점 = 리그 평균 득점 × 내 공격지수 × 상대 실점지수. 승률은 피타고리안(지수 1.83).
  • 표본이 작으면 리그 평균 쪽으로 당겨 계산합니다(타석 120·아웃 60·경기 3 기준 반반).
  • "리그 평균"은 이 도구에 등록된 모든 팀 기준입니다. 표본(타석·이닝)이 적으면 참고용으로만 보세요.
