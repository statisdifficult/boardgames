📖 텍사스 홀덤 규칙

목표

  • 내 홀카드 2장 + 공용 카드 5장 중 가장 좋은 5장 조합으로 팟(칩)을 따냅니다.
  • 노리밋 토너먼트 — 상대를 전부 탈락시키고 혼자 남으면 우승. 내 스택이 0이 되면 탈락이에요.

진행

  • 프리플랍: 각자 홀카드 2장. 딜러 버튼 왼쪽 두 명이 SB/BB 강제 베팅 (헤즈업에선 버튼이 SB).
  • 플랍(3장) → 턴(1장) → 리버(1장) 순으로 공용 카드가 깔리고, 매 단계마다 베팅합니다.
  • 액션: 폴드 / 체크 / 콜 / 벳·레이즈 (미니멈 레이즈 = 직전 인상폭 이상, 풀 레이즈만 액션 재오픈).
  • 전원 폴드하면 남은 한 명이 즉시 팟 획득(패 비공개). 올인끼리 남으면 패를 공개하고 보드를 끝까지 자동 공개(런아웃).
  • 올인 금액이 다르면 사이드팟으로 나눠 각자 낸 만큼만 겨룹니다. 블라인드는 10핸드마다 상승 (50/100부터 최대 4,000/8,000까지 10단계).

족보 (낮음 → 높음)

  • 하이카드 < 원페어 < 투페어 < 트리플 < 스트레이트 < 플러시 < 풀하우스 < 포카드 < 스트레이트 플러시 (A 하이는 로열 플러시).
  • A-2-3-4-5 백스트레이트도 인정됩니다 (가장 낮은 스트레이트).

이 판의 기능

  • 2~6인 (나 + AI 1~5명) · 시작 스택 10,000 · AI 난이도 쉬움/보통/어려움 — 새 게임부터 적용.
  • 레이즈는 슬라이더·직접 입력·프리셋(최소/½팟/팟/올인)으로. 언콜드 벳은 자동 반환됩니다.
  • 내가 탈락하거나 게임이 끝나면 최종 순위가 표시됩니다.
